# ADR 0008: 插件运行时以独立进程隔离为目标

- 状态：Accepted（Target）
- 日期：2026-07-25

## 背景

插件代码不可信，需防止拖垮或入侵宿主。

## 决策

目标架构：插件 main 运行在 **独立进程**（UtilityProcess/Child Process），经 RPC 访问 Host API。

MVP 若进度受限，可临时采用更轻隔离，但不得破坏：

- 权限网关
- API 白名单
- 贡献点统一注册
- 崩溃不致命

并需在实现 ADR 中注明临时方案与迁移计划。

## 理由

1. 崩溃隔离
2. 权限代理更清晰
3. 后续可加资源限制

## 后果

### 正向
- 安全性与稳定性更好

### 负向
- 实现与调试成本更高
