# ADR 0007: 插件分发包格式采用 .piplug（zip）

- 状态：Accepted
- 日期：2026-07-25

## 背景

需要一种便于本地分享与市场下载的插件包格式。

## 决策

采用 `.piplug` 作为产品层分发扩展名，内容为 zip 归档，根目录包含 `manifest.json`。

## 理由

1. 实现简单，跨平台
2. 易做 checksum / 签名
3. 对开发者友好（可本地解压检查）

## 后果

### 正向
- 工具链轻
- 与本地目录包可统一校验逻辑

### 负向
- 需要防止 zip slip 与超大包攻击

## 约束

- 安装前必须做路径安全检查
- 市场包至少提供 sha256
